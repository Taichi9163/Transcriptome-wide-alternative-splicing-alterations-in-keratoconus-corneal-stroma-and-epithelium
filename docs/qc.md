# Supplementary Figure 1 and Table 2: QC workflow

[Repository overview](../README.md) · [Documentation](README.md) · [Figure-to-code index](figures.md)

The supplied `STAR_junction_QC.py` is published as [supp_table_02_star_junction_qc.py](../scripts/supp_table_02_star_junction_qc.py). It calculates the STAR unique-mapping and splice-junction columns of Supplementary Table 2 from existing outputs. It uses the Python standard library, does not rerun alignment, and does not create figure images.

The subsequently supplied `Keratoconus_QC_ReadPairs.py` is published as [supp_figure_01b_qc_read_pairs.py](../scripts/supp_figure_01b_qc_read_pairs.py). It calculates the raw, filtered and mapped read-pair counts and can draw Supplementary Figure 1B. The supplied file explicitly describes itself as a reconstruction from the reported methods, not a verified copy of the original plotting code. The public version preserves its plotting function and calculation definitions; it does not assert visual identity to the manuscript panel.

## Coverage

| Component | Source and repository coverage |
| --- | --- |
| Supplementary Fig. 1A: per-base sequence quality | FastQC reports summarized with MultiQC; the `raw-qc` and `trimmed-qc` stages of `workflow_preprocess_reads.py` provide the commands |
| Supplementary Fig. 1B: raw, filtered and genome-mapped read-pair counts | `supp_figure_01b_qc_read_pairs.py` reads fastp JSON and STAR logs; `--tables-only` exports the counts without images |
| Supplementary Table 2: RIN | Study metadata, retained in `config/samples_stroma_qc.tsv`; not estimated by STAR |
| Supplementary Table 2: uniquely mapped pairs/percentage and junction support | Calculated by `supp_table_02_star_junction_qc.py` |
| Other Supplementary Table 2 columns: Q20, Q30, GC and total mapped percentage | Come from the original sequencing/QC reports; these columns are not exported by either QC script |

Raw and filtered pair counts are available in the Figure 1B TSV; check whether the manuscript table reports individual reads or pairs before transferring these values. The unique-mapping percentage must not be substituted for the total genome-mapped percentage. Together, these scripts provide the Figure 1B workflow and the STAR junction-summary columns; they do not reconstruct every QC report or table column.

## Inputs and sample identities

The default metadata includes all ten specimens (four controls, six cases), including study KC6. Row order determines output order. `sample_id` is the study label, `source_id` is the original read-file prefix, `sample_name` is the display label, and `rin` comes from the supplied study metadata. The source-ID mapping matches `config/samples_stroma.tsv`.

**Study KC1 corresponds to `KC_3`, study KC3 to `KC_6`, and study KC6 to `KC_1`.** Choose the filename convention explicitly; the script does not infer it from a case number.

| Options | Example expected files beneath `--star-dir` |
| --- | --- |
| Default: `--layout flat --file-labels study` | `KC1_Log.final.out`, `KC1_SJ.out.tab` |
| `--layout flat --file-labels source` | `KC_3_Log.final.out`, `KC_3_SJ.out.tab` for study KC1 |
| `--layout per-sample --file-labels study` | `KC1/KC1_Log.final.out`, `KC1/KC1_SJ.out.tab`, as emitted by `workflow_preprocess_reads.py align` |

## Run Supplementary Figure 1B

```sh
# Original Ubuntu filenames, for example KC_3_report.json and KC_3_Log.final.out:
python3 scripts/supp_figure_01b_qc_read_pairs.py \
  --fastp-dir /path/to/after_fastp --star-dir /path/to/after_star \
  --file-labels source --tables-only --output-dir work/results/qc/suppfigure1

# Outputs generated by this repository's upstream workflow:
python3 scripts/supp_figure_01b_qc_read_pairs.py \
  --fastp-dir work/results/upstream/trim --star-dir work/results/upstream/align \
  --layout per-sample --tables-only --output-dir work/results/qc/suppfigure1
```

For flat study-labelled files, omit `--file-labels source`: the expected files are `<sample_id>_report.json` and `<sample_id>_Log.final.out`. Per-sample fastp reports use `<sample_id>/report.json`. Both scripts accept the same `--samples`, `--layout` and `--file-labels` options. No filename-based guessing or automatic reassignment of KC numbers is performed.

The numeric output is `Keratoconus_Raw_Filtered_Mapped_Reads.tsv`. It includes raw, filtered, uniquely mapped, multimapped, total mapped and STAR input pairs. The plot displays millions of pairs. Remove `--tables-only` to write `Supplementary_Figure_1B_ReadPairs.png` and `.pdf`; install `matplotlib` and `numpy` for that mode. The default PNG resolution is 300 dpi (`--dpi` changes it). Numeric mode needs only the Python standard library. Existing different TSVs and existing figure files are preserved; use a new output directory for a new run.

This script expects unmerged paired-end processing. [fastp](https://github.com/OpenGene/fastp) summary `total_reads` includes both mates and is divided by two. STAR input and mapped counts are copied as pairs without division. Mapped pairs are uniquely mapped plus multiple-loci pairs; too-many-loci mappings are excluded. Odd fastp read totals, filtered totals exceeding raw totals, and mapped totals exceeding STAR input are rejected. STAR input must equal the fastp filtered-pair count; an inconsistency stops the public script rather than merely printing the warning in the supplied version.

## Run the summary

```sh
# Existing files with study labels, as expected by the supplied script:
python3 scripts/supp_table_02_star_junction_qc.py \
  --star-dir /path/to/after_star \
  --output work/results/qc/Supplementary_Table2_STAR_junction_QC.tsv

# Original Ubuntu filenames, with KC_*/N_* prefixes:
python3 scripts/supp_table_02_star_junction_qc.py \
  --star-dir /path/to/after_star --file-labels source \
  --output work/results/qc/Supplementary_Table2_STAR_junction_QC.tsv

# Outputs generated by this repository's upstream workflow:
python3 scripts/supp_table_02_star_junction_qc.py \
  --star-dir work/results/upstream/align --layout per-sample \
  --output work/results/qc/Supplementary_Table2_STAR_junction_QC.tsv
```

Use the example matching your files. `--samples /path/to/samples.tsv` selects a different metadata table. Input and output paths may be absolute; relative paths are resolved from `--work-dir`, then `KC_WORK_DIR`, or the current directory if neither is supplied. The default metadata path is resolved from the script location. Existing identical TSV output is reusable; a different existing output is preserved and produces an error. No FASTQ or BAM files are read.

## Definitions and validation limits

- STAR's unique count is copied from `Uniquely mapped reads number`; for this paired-end study it is reported as read pairs, without division by two. Its percentage is copied from `Uniquely mapped reads %`.
- A supported junction is an output row whose `SJ.out.tab` column 7 is at least one. Column 8 contains multimapper support and is not added. Counts describe junctions retained in the STAR output, not coverage of all possible junctions. See the [STAR manual](https://github.com/alexdobin/STAR/blob/master/extras/doc-latex/STARmanual.tex).
- Median, Q1 and Q3 are calculated after excluding zero unique-support rows, using linear interpolation equivalent to [R `quantile(type=7)`](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html). The output preserves the supplied script's two-decimal formatting with trailing zeros removed.
- Missing/invalid log fields, malformed junction rows, negative support and an empty supported-junction set stop the calculation. Different results are not silently substituted.

The original fastp JSON reports, STAR logs and junction tables were not available in the inspected local locations and are not bundled. Validation used synthetic fixtures: all ten output rows and TSV bytes matched the supplied script, 30 quartiles/medians matched R, and the filename mapping, invalid-input handling and output protection passed tests. This does not constitute an independent recomputation of the manuscript's sample-level QC values.

For Figure 1B, all ten synthetic sample rows and complete TSV bytes matched the supplied script, and the plotting function is unchanged. Tests also cover paired-end units, too-many-loci exclusion, source-ID mapping, invalid/mismatched inputs, and numeric-only execution with no plotting packages. No actual sample-level read counts or result images were regenerated.

Independent verification against the original QC logs is outside the agreed scope of this release. The implementation checks above remain separate from verification of the manuscript QC measurements.
